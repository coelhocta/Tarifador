# Tarifador Asterisk

Sistema para conciliação entre o CDR do Asterisk e a fatura telefônica da Vivo.

## Funcionalidades

- Importação do CDR do Asterisk
- Importação da fatura Vivo (PDF)
- Conciliação automática das chamadas
- Geração de planilhas Excel
- Estatísticas por ramal
- Relatórios de custos
